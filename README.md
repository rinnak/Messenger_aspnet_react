# Веб-мессенджер

Учебный веб-мессенджер для личной переписки. История хранится в PostgreSQL, а новые диалоги и сообщения появляются в открытом приложении через SignalR.

## Возможности

- Регистрация, вход и выход. ASP.NET Core Identity хранит хеши паролей, а запросы записи защищены CSRF-токеном.
- Поиск людей по логину и отображаемому имени. Для каждой пары пользователей создаётся один личный диалог.
- Отправка текстовых сообщений и подгрузка истории при прокрутке вверх. Сервер проверяет, что пользователь участвует в диалоге.
- Обновление списка чатов и открытой переписки в реальном времени. После переподключения клиент запрашивает пропущенные сообщения.
- Повторная отправка с тем же `clientMessageId` возвращает уже сохранённое сообщение. Публичные профили кэшируются в памяти сервера.
- Адаптивный интерфейс. На широком экране список и переписка видны вместе, на телефоне между ними можно переключаться.

## Стек

| Часть | Технологии |
| --- | --- |
| Сервер | C#, .NET 10, ASP.NET Core Web API, ASP.NET Core Identity, SignalR |
| Данные | PostgreSQL 18, Entity Framework Core, Npgsql, миграции EF Core |
| Клиент | React 19, TypeScript, Vite, React Router, CSS Modules |
| Запуск | Docker Compose |

Решение организовано по принципам **Clean Architecture**.

| Проект | Ответственность |
| --- | --- |
| `Messenger.Domain` | Сущности и правила диалога и сообщения |
| `Messenger.Application` | Сценарии приложения и контракты хранилищ |
| `Messenger.Infrastructure` | Доступ к PostgreSQL, Identity, кэш и миграции |
| `Messenger.Web` | HTTP API, SignalR, конфигурация и раздача сборки React |

## Скачать и запустить

Установи и запусти Docker Desktop или Docker Engine с Docker Compose. Скопируй URL репозитория и подставь его в команду:

```bash
git clone "URL_РЕПОЗИТОРИЯ" course_backend
cd course_backend
docker compose up --build
```


- [Мессенджер](http://localhost:8080/)
- [Swagger](http://localhost:8080/swagger/index.html)
- [Проверка запуска сервера](http://localhost:8080/health)

Профиль `LocalDocker` работает по HTTP на `localhost` и предназначен для локального запуска. PostgreSQL использует именованный том `postgres-data`. Данные сохраняются после `docker compose down`. При пересоздании веб-контейнера может понадобиться войти снова.
